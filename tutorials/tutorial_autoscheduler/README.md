# LOOPer autoscheduler tutorial

LOOPer is a learned automatic code optimizer for Tiramisu. It searches for
efficient loop-transformation schedules and can rank candidates with a learned
cost model or by executing them on the target machine.

The tutorial previously maintained in this directory described an obsolete
version of the autoscheduler and has been retired. The current, maintained
tutorial—including setup instructions, examples, and both model-guided and
execution-guided modes—is available in the
[LOOPer repository](https://github.com/Mascinissa/LOOPer).
